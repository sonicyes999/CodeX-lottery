# 抽獎管理系統（Web）

純前端網頁版抽獎程式，支援：
- 參與者後台管理（姓名、編號、權重）
- 多獎項設定（每個獎項可設定名額）
- 權重抽獎 / 一般抽獎
- 允許或禁止重複中獎
- 一鍵複製名單
- 下載參與者與中獎名單 CSV

## 使用方式

1. 直接開啟 `index.html`。
2. 在「參與者管理」貼上名單，每行：`姓名,編號,權重`。
3. 在「獎項管理」貼上獎項，每行：`獎項名稱,名額`。
4. 選擇抽獎設定後按「開始抽獎（全部獎項）」。

## 範例資料

參與者：

```text
王小明,001,1
陳小華,002,3
林小美,003,2
```

獎項：

```text
頭獎,1
二獎,2
三獎,3
```
